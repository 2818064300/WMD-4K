依据图像数据所呈现出的分布特征，本研究构建而成的晶圆微电路损伤数据集呈现出多维度的非均衡特性。该数据集共包含4531张高分辨率显微图像，涵盖阻挡刻蚀、涂层不良、粒子污染、PIQ粒子、PO污染、划痕和SEZ烧伤七种典型缺陷类型。其中，划痕类缺陷样本数量最多，共1589张，占据数据集的主要比例；阻挡刻蚀和粒子污染样本数量也相对较多，分别为845张和633张。相比之下，SEZ烧伤样本数量最少，仅109张，PIQ粒子和涂层不良等类别样本数量也相对有限。整体来看，该数据集具有明显的类别分布不均衡特征，高频缺陷类别与低频缺陷类别之间存在较大样本数量差异，这对后续缺陷识别模型的训练与泛化性能提出了更高要求。
